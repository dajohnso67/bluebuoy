| Group Classes |
| :---- |

We now know there are three group types — Parent & Me, Group (Stroke Prep), and Stroke Technique — all capped at 6 students. A few things that affect how scheduling gets built:

**1\.  What's the minimum for a group class to run?** If only one or two students are enrolled, does it still happen, get cancelled, or merge with another class?

*Answer: We keep the class open as group whether there are 1 student or none.  The only exception is if the class is completely open for the day and we need a sub for another teacher we will use the class for other options ( SP, PR, M SP, M PR, or PM)*

**2\.  Does the price change based on how full the class is?** Does a student in a class of 2 pay the same as one in a class of 6?

*Answer: price stays the same, regardless of how many students*

**3\.  How does a group student fit into the sibling discount?** Do they take up a "slot" the same way a private student does?

*Answer: we usually try to use the group class as the first lesson that way the more expensive classes get the discounted prices*

**4\.  How do group make-ups work?** They'd need a class with both an open seat and the right level — is that harder to arrange? Can they take it as a semi-private or private instead?

*Answer:  Group makes ( GR, ST, PM) can be used either as their lesson type OR if the family has more than one group make up they can use them as follows: 2 \=1 Semi Private make up, or 4= 1 Private make up.* 

**5\.  How do families join a group?** Do they join an existing class, or do you form a class once enough students want it?

*Answer: there are set times for all the different group classes that we offer.  that schedule typically stays the same year after year. . In order to join the group stroke tech or Prep.. the student must meet the age and swim level requirement. ( Stroke Prep Ages 7 and older Swim level 9-12, for Stroke Tech Ages 10 and older Swim Level 10-12. For Parent & Me groups there is no level requirement just need to be aged 0-3 years.*

**6\.  What is the Adult class?** Is it a group or individual, what's the capacity, and are there requirements?

*Answer: the adult class is a group class. I believe it can have up to 6 in a class age 16 years or older. This payment is set up differently, they can pay for a single class, a package of 4 or a package of 8 lessons.  We only take a lesson from their account if they show for a class (based on teacher’s roll for the day) However, we run into a problem that the adult doesn’t notify us if they will be out.. We need to look into a way improve on this.* 

| Make-Up Credit Conversions |
| :---- |

We heard there's a formula for trading make-up credits between lesson types — something like a few group credits equaling one semi-private, or about four group equaling one private.

**7\.  Is that right, and what are the actual ratios?**

*Answer: Yes.  2 Semi Private make ups \=1 Private make up, 1 Private make up= 2 Semi Private make ups,  2 Group( St, GR, PM) \=1 Semi Private make up,  4 Group( St, GR, PM) \=1 Private make up,  and 1 Private make up \= 4 Group make ups.*


**8\.  Which conversions are allowed?** Group → semi-private? Group → private? Semi-private → private?

*Answer:  Yes*

**9\.  Does it work in reverse?** Can a private credit be split into several group credits?

*Answer: Yes*

**10\.  Who decides?** Is it automatic, or does someone approve each conversion?

*Answer:  When scheduling the make up we choose which option we want to use.  However, when moving make ups between siblings we note how many make ups and type of make up moved from one child to the other.* 

**11\.  What happens to a student's existing private credits if they switch to group lessons?**

*Answer:  They stay as Private make ups and can be used as either Private or convert to other make up options.*

| A Few Loose Ends |
| :---- |

**16\.  The military discount** — how much is it, and does it stack with the sibling and prepay discounts?

*Answer:  Yes, we offer a additional 10% discount for First responders ( Military, Police & Fire department) We ask them to provide ID to verify. I would like an option to flag if this has been provided. Yes, the discount stacks on both sibling and pre pay discounts.* 

**17\.  Monthly credit card volume** — last time the answer was "550–700." Is that the number of transactions, or dollars? (This decides whether we stay with our current card processor or switch.)

*Answer: This is about how many students/families we process per month. Monthly credit card volume ranges from \~$156,000-207,000.  Charter schools that pay by direct deposit or check have increased in volume to \~15% of income.  Estimated 2026 total gross income: $2,650,000*

**18\.  Which file is the real one** — BlueBuoy\_FM or BlueBuoy\_FM\_2024?

*Answer:  We use Bluebuoy\_FM currently.. The FM\_2024 is a history file. What happens is our system slows due to too many files, so we archive families that have not been enrolled for 10 years. We still need access to the old files (rarely) but need to see just in case a family returns years later.* 

**19\.  How is a substitute found today** when a teacher calls out? Walk us through it.

*Answer: Well, we look at both the teacher that is out schedule and cross reference other teachers that work during that time and see what openings they have that might have a open spot, a student out, or a student starting the week after making the current day available. Some times we need to be aware that the student needs to have special request. Like female only teachers,  to pair higher or lower, if they have a sibling enrolled around that time we want to find a spot either same time or after for student that needs the sub. When we can’t find anything we look around that time or the students availability from previous request to see what we can offer if they have flexibility for the day. When all else fails we have a on call teacher take lessons we could not fill in.* 

**20\.  Has a lesson ever been scheduled during someone's lifeguard shift** by mistake? (Our system won't know about guard shifts — those only live in Humanity.)

*Answer:  Only if we have to switch them from guarding to subbing for the day.*
